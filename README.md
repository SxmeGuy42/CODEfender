# CODEfender

An AI-powered security agent with a GUI, built on Kiro CLI. It is configured through steering files that guide it to perform reliable code security checks while avoiding false positives.

## What CODEfender does

1. **Clear reports** — Generates easily understandable security reports.
2. **Actionable output** — Lets you choose between a detailed explanation of each vulnerability (with a recommended fix) or an automatically patched version of the file.
3. **Interactive answers** — Responds to your follow-up questions about the findings.

## How to download and install CODEfender

1. *Download the CODEfender folder*
2. *Open the `FIRST-START` folder*
3. *Read `README.md` and follow the installation instructions*
